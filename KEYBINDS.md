# Artcava — Keyboard & Mouse Controls

Everything you need to control Artcava without leaving your terminal.

---

## 🎵 Music Playback

Control your music directly from the main visualizer.

| Key | Action |
|:---:|---|
| `A` | **Previous track** |
| `Space` | **Pause / resume playback** |
| `D` | **Next track** |

You can also use the clickable playback controls in the **top-right corner** of Artcava:

| On-screen control | Action |
|:---:|---|
| `[<<]` | Previous track |
| `[||]` | Pause / resume playback |
| `[>>]` | Next track |

---

## 🎤 Lyrics

Toggle synced lyrics and fine-tune their timing while music is playing.

| Key | Action |
|:---:|---|
| `L` | **Show or hide synced lyrics** |
| `[` | Move lyric timing **0.25 seconds earlier** |
| `]` | Move lyric timing **0.25 seconds later** |

---

## 🖥️ Display

Choose whether track information is shown above the visualizer.

| Key | Action |
|:---:|---|
| `T` | **Show or hide song information** (title, artist, and album) |

---

## ⚙️ Settings Menu

Press `S` while the visualizer is active to open the settings menu. Changes apply immediately and are saved automatically.

| Key | Action |
|:---:|---|
| `↑` / `↓` | **Navigate** through the settings |
| `←` / `→` | **Decrease or increase** the selected setting |
| `Enter` | **Select or increase** the selected setting |
| `S` / `Esc` | Close the settings menu |
| `Q` | Close the settings menu |

---

## 🚪 General

| Key | Action |
|:---:|---|
| `Q` | **Quit Artcava** from the main visualizer |

> **Note:** `Q` closes the settings menu when the menu is open. From the main visualizer, it exits Artcava.

## 🔄 Updates

Artcava can check GitHub for new releases without forcing you to update.

| Key | Action |
|:---:|---|
| `U` | **Update now** — Copy the GitHub source link and open it in your browser |
| `X` | **Update later** — Dismiss the update notification |

*These shortcuts are active when an update notification is displayed.*

### Manually Check for Updates

1. Press `S` to open Settings.
2. Navigate to **Check for updates** using `↑` / `↓`.
3. Press `Enter` to check GitHub.
4. If an update is available, press `U` to open it or `X` to postpone it.

**Updates are optional. Artcava never forces an update.**
**That's all you need to know.** Keep this page nearby as a quick reference while using Artcava.
